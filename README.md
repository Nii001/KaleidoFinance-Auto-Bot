## 🚀 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/airdropinsiders/KaleidoFinance-Auto-Bot.git
   cd KaleidoFinance-Auto-Bot
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a wallets.txt file and add your wallet addresses (one per line):0x063CC5FB03f684DC2A45344B4EeB0C8a0E05319c
   ```bash
   nano wallets.txt
   ```
4. Run Bot
   ```bash
   npm run start
   ```
